# chats

A personal **DeepSeek Harness (`dsh`) agent workspace** — notes, reasoning drafts, and
agent setup, kept in a repo so it's versioned, shareable, and reusable. This repository is
the home base for how `dsh` is configured here and for the thinking/operating model it
runs under.

For the human reading this first: the short answer is "what this repo is, what's inside,
and how to use it." The rest of the doc set is split deliberately by role so nothing
duplicates.

---

## What this is

This directory is the **workspace** (`cwd`) for `dsh` sessions here. It holds:

- The **thinking model** and **operating rules** the agent follows.
- A curated set of **agent skills** (project scoped).
- **Reference notes** on how `dsh` works.
- Topic sub-folders (`ai/`, `rust/`) for future chat/notes organization.

It is intended to be **the one place you and `dsh` work from**, with the conventions
carried in the docs so they survive a fresh machine or a new teammate.

## Which file does what (the map)

| File | Audience | Purpose |
|---|---|---|
| **`README.md`** | human | Entry point: what this repo is, the layout, how to use it. |
| **`AGENTS.md`** | `dsh` agent | Operating rules the agent follows automatically in this workspace. Read by `dsh`'s `agent-instructions`. |
| **`INTRO.md`** | human | Reference: how `dsh` works (profiles, skills, sandbox, workspaces, `cwd`) + a description of the installed skills. |
| **`THINK.md`** | human + agent | The base mind: the thinking doctrine (derive by default, gate the fast path, always slow in planning) and the reasoning behind that decision. |
| **`PATCH.md`** | operator | Ready-to-paste block to set the deployment persona (system prompt, order 0). Not yet applied — see below. |
| **`.dsh/skills/`** | `dsh` agent | Task procedures (grilling, tdd, code-review, etc.) loaded on demand. |
| **`ai/`, `rust/`** | human | Empty topic folders you can use for chat/work notes. |

## How to use it

- **Chat with `dsh` from here**: open a session with this directory as its working
  directory. The agent automatically reads `AGENTS.md` and inherits the `THINK.md` mind.
- **Pick a task procedure** (interviews, TDD, code review): the agent can load the
  relevant skill from `.dsh/skills/` on demand. User-invocable ones use `/name`, e.g.
  `/grill-me`.
- **Add a note/topic**: put it in the matching folder (`ai/`, `rust/`) or a new one.

> Note on the persona: the system-wide `deployment:persona` is **not** applied yet — the
> thinking doctrine currently arrives via `AGENTS.md` + `THINK.md` (this workspace) rather
> than the global system prompt. See `PATCH.md` if you want to make it global.

## The thinking model (in one line)

Derive from first principles by default; treat every fast answer as a *hypothesis* and
gate it with a check (novel / high-stakes / uncertain?); and in planning + thinking, always
go slow — never gate that. Full rationale and wording in [`THINK.md`](THINK.md).

## Git conventions (also encoded in `AGENTS.md`)

- Default branch is **`master`** (not `main`).
- One-line, atomic commits; review with `lg` (`git log --oneline --graph --decorate --all`).
- **No authorship/attribution markers.** `dsh` acts *as the user* — every commit is the
  user's own; no `Co-authored-by`, no "generated by dsh".

## Getting started with the remote

This repo is intended to live at `git@github.com:zungfu/chats.git`. From a fresh clone:

```bash
git clone git@github.com:zungfu/chats.git
```

Then open `dsh` with this directory as the workspace and follow `README.md`.
